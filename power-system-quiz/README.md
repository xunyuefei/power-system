## 🌟 项目亮点

1. **题目完整收录**：
   - 收录华北电力大学本科期末考试（317 题）与硕士入学考研真题（472 题），**共计 789 道纯选择与判断题**。
   - 所有题目严格划分所属年份、试卷类型、八大核心知识章节，并配有参考答案、解析与争议核对说明。
2. **六大沉浸式刷题模式**：
   - 📝 **顺序狂刷**：按试卷年代地毯式通关，沉浸式一屏一题。
   - 🎲 **随机突击**：全真随机抽题，打破位置惯性，真实检验复习成效。
   - ❌ **错题消灭营**：自动汇总所有历史做错题目，重做答对后自动移出，精准补漏。
   - ⭐ **重点收藏夹**：自主标星易混淆、经典考点题目，考前随时回顾。
   - 📊 **八大章节专练**：覆盖电网基础、线路变压器参数、潮流手算与机算、有功无功调频调压、短路与不对称故障。
   - 📋 **全真模拟考**：自定义题量（20/30/50题）与限时，倒计时时钟仿真考场，交卷后自动生成分析报告与错题复盘。
3. **PWA 渐进式离线应用能力**：
   - 📶 **无网畅刷**：配置 Service Worker 与离线缓存引擎，即便在地铁、飞行模式等无网络环境下依然能秒开畅刷全部 789 题。
   - 📲 **一键安装为独立 App**：无浏览器地址栏和工具栏干扰，像原生 App 一样享受全屏沉浸体验。
   - 🔄 **多端一键口令同步**：支持电脑端与手机端通过「同步口令」在微信/QQ复制粘贴，秒级互通刷题记录与错题本。
4. **极佳用户体验**：
   - 🌌 **深色科技护眼视觉**：毛玻璃质感、微光渐变，长时间刷题不眼疲。
   - 🔣 **内置公式渲染引擎**：纯轻量原生实现，457 处 LaTeX 复杂数学与电力物理符号极速美化呈现。
   - 📱 **移动端全方位优化**：底部功能快捷导航条、手势左右滑动切题。
   - ⌨️ **全键盘快捷键**：`A / B / C / D` 选选项，`Enter` 提交答案与下一题，`← / →` 快速切题，`/` 快速检索。

## 📲 如何安装为桌面 / 手机 App (PWA)

### 1. 苹果 iPhone / iPad (iOS Safari)
1. 在 Safari 浏览器打开：`https://xunyuefei.github.io/power-system-quiz/`
2. 点击底部中间的 **「分享」图标**（方框向上箭头）。
3. 往下滑动并选择 **「添加到主屏幕」**。
4. 主屏幕上即会出现「电分刷题宝」App 图标，点击即可全屏无缝离线使用！

### 2. 安卓手机 (Android Chrome / 微信外部浏览器)
1. 在 Chrome 等浏览器打开网址。
2. 点击右上角或网页内 **「📲」/「添加到主屏幕 / 安装应用」** 按钮。
3. 确认添加到桌面即可生成独立 App 图标。

### 3. 电脑端 (Chrome / Edge)
1. 在 Chrome 或 Edge 地址栏右侧点击 **「安装 华电电分刷题宝」** 图标。
2. 安装后将在桌面与开始菜单生成应用快捷方式，拥有独立独立窗口体验。

## 📂 文件清单
- `index.html`：刷题主系统前端单文件（包含所有现代 UI 样式与交互引擎）。
- `questions_data.js`：从 Markdown 编译解析生成的结构化 JSON 题库（789 题）。
- `manifest.json`：PWA 应用清单配置文件。
- `sw.js`：PWA 离线 Service Worker 缓存脚本。
- `icon.svg` / `icon-192.png` / `icon-512.png`：PWA 矢量与高清应用图标。
- `generate_icons.py`：PWA 高清图标生成脚本。
