# ⚡ 华北电力大学《电力系统分析》全真题库·智能刷题系统

> **零环境依赖 · 纯前端离线运行 · 双击即用 · 数据自动本地持久化**

---

## 🌟 项目亮点

1. **题目完整收录**：
   - 收录华北电力大学本科期末考试（317 题）与硕士入学考研真题（472 题），**共计 789 道纯选择与判断题**。
   - 所有题目严格划分所属年份、试卷类型、八大核心知识章节，并配有参考答案、解析与争议核对说明。
2. **六大沉浸式刷题模式**：
   - 📝 **顺序狂刷**：按试卷年代地毯式通关，沉浸式一屏一题。
   - 🎲 **随机突击**：全真随机抽题，打破位置惯性，真实检验复习成效。
   - ❌ **错题消灭营**：自动汇总所有历史做错题目，重做答对后自动移出，精准补漏。
   - ⭐ **重点收藏夹**：自主标星易混淆、经典考点题目，考前随时回顾。
   - 📊 **八大章节专练**：覆盖电网基础、线路变压器参数、潮流手算与机算、有功无功调频调压、短路与不对称故障。
   - 📋 **全真模拟考**：自定义题量（20/30/50题）与限时，倒计时时钟仿真考场，交卷后自动生成分析报告与错题复盘。
3. **极佳用户体验**：
   - 🌌 **深色科技护眼视觉**：毛玻璃质感、微光渐变，长时间刷题不眼疲。
   - ⌨️ **全键盘快捷键**：`A / B / C / D` 选选项，`Enter` 提交答案与下一题，`← / →` 快速切题，`/` 快速检索。
   - 📋 **全景答题卡抽屉**：随时点击右上角展开 789 题做题状态方阵，一键秒跳转定位。
   - 💾 **进度无损保存**：所有刷题进度、对错、重练次数、收藏与笔记全自动保存在浏览器 `localStorage` 中，关掉页面绝不丢失。
   - 📦 **支持备份与迁移**：提供数据 JSON 导出与恢复功能，换电脑刷题也能无缝同步进度。

## 🚀 启动与使用方式

### 方式一：直接双击（推荐，最简便）
直接在资源管理器中找到当前目录下的 `index.html`，**双击**即可用默认浏览器（Chrome、Edge、Firefox 等）打开刷题！

### 方式二：本地服务器运行
在当前目录运行终端命令：
```bash
python -m http.server 8088
```
然后在浏览器地址栏输入并访问：
[http://localhost:8088/index.html](http://localhost:8088/index.html)

## 📂 文件清单
- `index.html`：刷题主系统前端单文件（包含所有现代 UI 样式与交互引擎）。
- `questions_data.js`：从 Markdown 编译解析生成的结构化 JSON 题库（789 题）。
- `parse_to_json.py`：从题库 Markdown 文件自动抽取与校核分类的 Python 转换脚本。
